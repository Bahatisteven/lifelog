# LifeLog
A personal activity insights generator that helps you track and analyze your daily activities, moods, sleep, meals, and more — providing valuable insights into the patterns shaping your life.

## Features
- Track daily activities with timestamps
- Analyze patterns and trends
- Generate weekly and custom date range summaries
- Advanced analytics with pandas and visualizations
- Export insights to reports

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python main.py`

## Usage
Simply run `python main.py` and follow the interactive menu to:
- Add new activities
- View logs and summaries
- Generate custom date range reports
- Filter by tags
- Export insights
